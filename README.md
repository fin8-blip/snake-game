# Snake Game 🐍

Game Snake sederhana yang dibuat dengan JavaScript vanilla dalam satu file HTML.

## Cara Bermain

- Gunakan **panah** atau **WASD** untuk menggerakkan ular
- Makan makanan merah untuk menambah skor dan memperpanjang ular
- Jangan menabrak dinding atau tubuh ular sendiri
- Di HP, geser layar untuk bergerak
- Tekan **Spasi** untuk mulai, jeda, atau ulangi

## Teknis

- 100% JavaScript vanilla, tanpa library eksternal
- Satu file: `index.html`
- Skor rekor disimpan di `localStorage`
- Responsif untuk desktop dan mobile (sentuhan)

Game ini di-deploy menggunakan **GitHub Pages**.
